# Contributing

- Sign off every commit with `git commit -s`. This is the Developer
  Certificate of Origin, https://developercertificate.org.
- Commit format: `<type>(<scope>): <subject>`. Types: feat, fix, docs,
  style, refactor, test, chore, perf. Subject 50 characters or fewer,
  imperative mood, no period.
- One logical change per commit.
- Run `make test` before opening a pull request.
- No comments in code or manifests. Names and structure explain the code.
